# Historical restoration source

These are retained snapshots of the colour, denoise, blend, sharpen, batch and
report experiments leading to the selected recipe. They preserve the calculations
and historical paths; they are not supported runnable entry points. Use the active
restore_batch.py and verify.py in the parent directory.

maintenance/ preserves one-time consolidation/JPEG-only cleanup scripts as records
of completed work. They can move/delete derivative files or rewrite metadata and
must not be rerun as routine processing. No new cleanup is authorized by preserving
the source. Private input lists, recipes with image records, manifests, runtime
logs, audits and comparison photos remain in the external local RestorationLab.
